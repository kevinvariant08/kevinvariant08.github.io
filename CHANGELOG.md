# Changelog

## Unreleased

- 2026-10-24. New ESAT section: an ESAT hub and ESAT Drill, with ESAT mock Set A (Mathematics 1 and Mathematics 2, 27 questions in 40 minutes each, free, with worked solutions and PDFs). The site now describes itself as Oxbridge admissions test (TMUA and ESAT) and olympiad preparation. New site icon: the inverted trefoil knot.
- 2026-10-23. TMUA mock Set L (Papers 1 and 2), locked from the start: unlock each paper with a challenge code or 4,000 coins. Both papers rate 8.3, the hardest in the collection.
- 2026-10-23. The TMUA hub no longer lists the topics inside each mock paper, so a paper can be sat without knowing what is coming.
- 2026-10-22. Sets E, F, G, H and K are now locked: unlock each paper with a challenge code or with coins in the Shop. Sets A to D stay free.
- 2026-10-22. TMUA mock Set K (Papers 1 and 2), free: in the question bank, timed drill, technique index and as PDFs with worked solutions.
- 2026-10-22. Problem editor (marker-admin.html, admin only): write Proof marker problems with a live LaTeX preview and publish them straight to the site, hide built-in problems, and draft mark schemes and examples with the free model.
- 2026-10-22. Proof marker: a problem library with problem-specific mark schemes and examiner-marked examples, two-pass marking (an independent check, then a re-mark if it finds something serious), a checkpoint-by-checkpoint report, a free marker with no key needed, history with an improvement reward, and a tool for measuring agreement with the examiner.
- 2026-10-22. Trap Map: when a wrong option in Drill, the question bank or Review comes from a common mistake, the site names that mistake, and Progress shows a Trap Profile with a short drill for each trap.
- 2026-10-22. Corrected the answer key for Set G Paper 2, question 8.
- 2026-10-22. Long formulas no longer make question pages scroll sideways on phones.
- 2026-10-22. Confidence calibration: say Guess, Unsure or Sure before an answer is checked in Drill or the question bank; Progress compares your confidence with your results, and a well-calibrated week earns a small bonus.
