Locked papers

TMUA mock Sets E onwards are locked. Challenges are posted from time to time, and winners get a code that unlocks a paper. Every locked set except Set J can also be unlocked with coins in the Shop. Once you unlock a paper it stays unlocked on your account, on every device. How access works.

Challenges are posted on Instagram: @kevinvariant.

The papers

How codes work

  • A code unlocks one paper, or occasionally every locked paper. Letters are not case-sensitive, and the dashes are optional.
  • Some codes can be claimed only once, and some only by the first few people, so redeem yours promptly.
  • Re-entering a code you have already used is harmless: it will not use up a claim.
